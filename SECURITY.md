# Security Policy

## Supported versions

Security fixes are provided for the latest GitHub release.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/Zeclown/Moodeur/security/advisories/new).
Do not disclose a suspected vulnerability in a public issue, discussion, or
pull request.

Include the affected version, operating system, reproduction steps, impact,
and any suggested mitigation. You should receive an acknowledgement within
seven days. A coordinated disclosure date will be agreed upon after the issue
has been validated and a fix is available.
